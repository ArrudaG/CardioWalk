# Cardio Walk Pet  

O objetivo do projeto é, criar um aplicativo para acompanhar a saúde do seu pet durante caminhadas e passeios.  

## Pré-requisitos  

- [.NET SDK](https://dotnet.microsoft.com/download)
- [Node.js](https://nodejs.org/)
- Aplicativo **Expo Go** no celular ou um emulador configurado.  

## Instalação (Primeira vez)  

```bash
cd frontend
npm install
```  

## Como Executar  

*Backend (.NET)*
```bash
cd backend
dotnet run
```  

*Frontend (Expo)*
```bash
cd frontend
npx expo start
```
